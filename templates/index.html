Import Data

1) Go to "Database" tab.
2) Select a directory to which new gpx files are added (create a new directory if none exists)
3) Click "Browse" and select gpx files from your filesystem.
4) Click "Upload GPX files".

Plot Routes

1) Go to "Plot Routes on Map" tab.
2) Select at least one source directory and an activity type.
3) Specify a time intervall: activities before or after this intervall are not considered.
4) Select a reference GPS point on the map and a maximum distance: activities further away from the reference point are not considered. Also note that the map detail level of the map widget will also be used for your map: choose a fitting detail level, e.g. 14 for running, 13 for hiking, 11-12 for cycling.
5) Provide an optional filename.
6) Click "Create Map".

Plot Data Visualization Graphs

1) Go to "Visualize Data" tab.
2) Select at least one source directory and an activity type.
3) Specify a time intervall: activities before or after this intervall are not considered.
4) Choose which dimensions are plotted on x- and y-axis.
5) Provide an optional filename.
6) Click "Create Plot".
