Home

Import Data

1) Go to "Upload" tab.
2) Select an athlete to which new activities are added (create a new athlete if necessary).
3) Click "Browse" and select gpx files from your filesystem.
4) Click "Upload GPX files".

Note that the selected gpx files are copied into the folder 'gpxdata'. You can delete the original file.

View Database

1) Go to "Database" tab.
2) Choose athletes, activity-types and a date range.
3) Click "Show relevant activities".

Plot Graphs

1) Go to "Statistics" tab.
2) Choose athletes, activity-types and a date range.
3) Click "Show relevant activities".
4) In the overview table, (de-)select all activities that you want to be contained in the graph.
5) Below, select which attributes are used for the plot by setting the x- and y-axis.
6) Provide a filename and click "Create statistics plot".

The resulting plot is stored as a .png-file in otuput/activities

Plot Route Overview on Map

1) Go to "Map" tab.
2) Choose athletes, activity-types and a date range.
3) Select a reference GPS point on the map and a maximum distance: activities further away from the reference point are not considered.
4) Note that the map detail level of the map widget will also be used for your map: choose a fitting detail level, e.g. 14 for running, 13 for hiking, 11-12 for cycling.
5) Click "Show relevant activities".
6) In the overview table, (de-)select all activities that you want to be contained in the graph.
7) Provide a filename and click "Create Map".

The resulting map is stored as a .png-file in otuput/maps

Create Animated Tour

1) Go to "Animations" tab.
2) Choose athletes, activity-types and a date range.
3) Select a reference GPS point, a maximum distance and a map detail level (as described above).
3) Specify a time intervall: activities before or after this intervall are not considered.
4) Choose which dimensions are plotted on x- and y-axis.
5) Click "Show relevant activities".
6) In the overview table, (de-)select all activities that you want to be contained in the animation.
7) Provide a filename and click "Create animated tour visualization".

The resulting animation is stored as a .mp4-file in otuput/animations
